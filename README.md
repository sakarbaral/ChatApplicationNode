# Chat Application

This project is a basic chat application built using Node.js and Socket.io. It allows users to join chat rooms, send messages, and share their current location with others in the room. The location link, when clicked, opens the exact spot in Google Maps.


## Features
- Join Multiple Rooms: Users can join specific chat rooms to communicate with others in that room.
- Real-Time Messaging: Messages are instantly broadcasted to all participants in the room.
- Location Sharing: Users can share their current location with others, which can be viewed directly on Google Maps.


## Installation and Usage

1. Clone the repository:
   ```
   git clone https://github.com/sakarbaral/ChatApplicationNode.git
   cd ChatApplicationNode
   ```
2. Install dependencies:

    ```npm install```

3. Run the application

    ```node server/app.js```

3. Open the application on the browser at ```localhost:5000```

4. Enter your name and the name of the room you want to join
   
5. If a room of that name is not already present, it will create one
